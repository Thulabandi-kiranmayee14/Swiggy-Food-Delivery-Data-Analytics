# Swiggy Food Delivery Data Analytics & Interactive Dashboard
# Project Overview

This project focuses on analysing Swiggy food delivery data to understand customer behaviour, restaurant performance, cuisine preferences, delivery efficiency, payment patterns and order cancellations.

The project combines Python-based Data Analysis and Power BI Dashboard Development to transform raw food delivery data into meaningful business insights and interactive visual reports.

Python is used for data preprocessing, cleaning, Exploratory Data Analysis (EDA), statistical analysis and visualization, while Microsoft Power BI is used to develop an interactive dashboard that presents important business metrics and trends in an easy-to-understand format.

The main objective is to identify patterns in food delivery operations and provide data-driven insights that can support better business decisions.
# Project Objectives

Analyse Swiggy food delivery data to understand customer ordering behaviour.

Perform data cleaning, preprocessing and duplicate checking.

Conduct Exploratory Data Analysis using Python.

Analyse city-wise, restaurant-wise and cuisine-wise order patterns.

Evaluate delivery performance and customer satisfaction.

Investigate payment preferences and order cancellation trends.

Create visualizations using Python libraries.

Develop an interactive Power BI dashboard.
